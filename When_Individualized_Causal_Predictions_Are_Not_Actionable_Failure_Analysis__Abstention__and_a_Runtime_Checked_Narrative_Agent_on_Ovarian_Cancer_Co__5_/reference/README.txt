Reference-only files. Neither is a submission artifact.

CONTENT_MASTER.docx
  Word rendering of main.tex, regenerated from the updated source with pandoc so it cannot
  drift from the LaTeX. Citations are rendered author-year; LaTeX math is flattened.

CONTENT_MASTER_REFERENCE.pdf
  Local preflight compile of main.tex. The official neurips_2026.sty was NOT used, because
  it is not distributed in this package. Layout, type size, line numbers and pagination in
  this PDF therefore do NOT match the workshop template and must not be used to judge
  length or formatting. Compile with the official style file before upload.
